### 数据类型
java是强类型语言，所有变量必须先定义才能用  
基本数据类型：整数（byte-1B,short-2B,int-4B,long-8B-结尾需要加L表示long）,浮点类型（float-4B-结尾加F,double-8B），字符（char-2B）,boolen（占一位）  
引用数据类型：类，接口，数组  
float与double：  
精度和范围不一样，避免进行比较  
==比较是否指向同个对象，String 对象的内容创建后不能修改。例如 s3 = "hello" 只是让 s3 指向另一个对象，不会改变原来的 "hh"。字符串常量池是让相同的字符串共享同个对象。  

### 类型转换
强制转换(低->高)：  
    (强制转换的类型)变量名，如int i=1;char c=(char)i;  
自动转换(高->低)：  
    double>float>long>int>char,byte,short  
**注意**
1. 布尔类型不能转换
2. 不能把对象类型转换成不相干的类型？
3. 转换可能存在溢出或者精度问题

### 变量
数据类型 变量名 = 值;  
变量名必须是合法的标识符  
变量作用域：类变量(类中，方法外，加static，有默认初始值int-0/double-0.0/boolen-false/除基本类型外的类型-null，共享的值)，实例变量(类中，方法外，不加static，有默认初始值int-0/double-0.0/boolen-false/除基本类型外的类型-null)，局部变量(方法内，必须声明且使用前必须赋值)  
常量：final 数据类型 常量名=值，不可改变，一般使用大写字母  
修饰符：static,final，不区分前后顺序  
变量命名：
1. 类成员变量：lastName
2. 局部变量：lastName
3. 常量：全部大写
4. 类名：LastName
5. 方法名：lastName

### 运算符

5. 位运算：&，|，^，>>，<<，>>>(无符号右移)

7. 扩展赋值：+=，-=，/=，%=，*=
