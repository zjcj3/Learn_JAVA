### 构造器

```java

// 没有返回类型，也不能写 void

// 拷贝构造器（浅拷贝）

public Student(Student student) {
    this.name = student.name;
    this.age = student.age;
}
```

### 浅拷贝与深拷贝

**浅拷贝：**
- 基本数据类型：复制实际数值。
- 引用类型：复制引用，可能导致多个对象共享同一块数据。

**深拷贝：**
- 基本数据类型：复制实际数值。
- 引用类型：创建新的对象或数组，使其与原对象的数据相互独立。

例如，添加 `int[] scores` 成员变量：

```java
// 深拷贝构造器
public Student(Student student) {
    this.name = student.name;
    this.age = student.age;
    this.scores = student.scores.clone();
}
```

**注意：**
1. String 虽然是引用类型，但由于其不可变性，通常不需要深拷贝。
2. 数组可以使用 clone() 创建新数组。
3. 如果数组元素是对象，clone() 仍然只是浅拷贝，需要进一步复制数组中的对象。
4. 如果对象内部还有其他引用类型成员，也需要递归考虑深拷贝。

### 对象的内存分析

**1. 内存区域**

| 内存区域 | 主要存放内容 |
|---|---|
| 栈（Stack） | 局部变量、对象引用等 |
| 堆（Heap） | `new` 创建的对象、数组等 |
| 方法区（Method Area） | 类信息、静态变量等 |

**2. 对象创建**

```java
Student s1 = new Student();
```

- `new`：在堆中创建 Student 对象。
- `s1`：栈中的引用变量，指向堆中的对象。
- 对象成员变量初始化为默认值。

**3. 引用赋值**

```java
Student s2 = s1;
```

- 不会创建新的对象。
- 将 s1 保存的引用复制给 s2。
- s1 和 s2 指向同一个对象。
- 通过任意一个引用修改对象成员，都会影响另一个引用访问的结果。

**4. 对象拷贝**

```java
Student s2 = new Student(s1);
```

- 创建一个新的 Student 对象。
- 通过构造器复制原对象的数据。
- 浅拷贝：引用类型成员可能共享数据。
- 深拷贝：引用类型成员也创建独立对象。

**核心：** `new` 创建对象，引用变量用于访问对象；引用赋值不创建新对象。

### 访问修饰符

#### 1. 四种访问权限

| 修饰符 | 同一个类 | 同一个包 | 不同包的子类 | 不同包的非子类 |
|---|:---:|:---:|:---:|:---:|
| `public` | ✓ | ✓ | ✓ | ✓ |
| `protected` | ✓ | ✓ | ✓ | × |
| `default`（默认） | ✓ | ✓ | × | × |
| `private` | ✓ | × | × | × |

#### 2. 使用位置

| 使用位置 | public | protected | default | private |
|---|:---:|:---:|:---:|:---:|
| 成员变量 | ✓ | ✓ | ✓ | ✓ |
| 方法 | ✓ | ✓ | ✓ | ✓ |
| 顶层类 | ✓ | × | ✓ | × |
| 内部类 | ✓ | ✓ | ✓ | ✓ | 

**注意：**
- `default` 不是关键字，不写访问修饰符时默认为 default 权限。
- 顶层类只能使用 `public` 或 default。
- `protected` 在不同包的子类中可以访问，但有访问条件。
- `private` 只能在当前类内部访问。

**记忆：**
- `public`：公开，任何地方都能访问。
- `protected`：同包及不同包的子类。
- `default`：同包访问。
- `private`：当前类内部访问。

### instanceof
是否是该类或其子类，看实际类型
```java
        Student student = new Student("Tom");
        student.print();

        Person p2 = new Person("Jerry");
        p2.print();

        System.out.println(student instanceof Student); //true
        System.out.println(student instanceof Person); //true，Student继承Person
        System.out.println(student instanceof Object); //true

        System.out.println(p2 instanceof Student); //false，p2是Person，并不是Student的子类
        System.out.println(p2 instanceof Person); //true
        System.out.println(p2 instanceof Object); //true

        //类型转换
        //向上转型会自动转换，向下转型需要强制转换
        //派生类转基类，会丢失自己的方法，通过强制转换可以继续使用
        //若Student加了一个Person中没有的方法say()
        Person p = new Student();
        p.say();   //报错

        ((Student) p).say(); //成功

        //可以使用 instanceof 判断后再转换
        if (p instanceof Student) {
            Student student = (Student) p;
            student.say();
        }  
```

        void eat();

        void eat();
    }

        @Override

            System.out.println("Eating food");

    //多个接口有相同的default方法

        default void eat() {
            System.out.println("A");
        }
    }

    interface B {
        default void eat() {
            System.out.println("B");
        }
    }

    class C implements A, B {
        @Override
        public void eat() {
            A.super.eat();
            B.super.eat();
        }
    }

### 异常Exception
关键字：try,catch,finally,throw,throws
```java
public class LearnException {
    public static void main(String[] args) {
        try {
            int result = 10 / 0; // This will throw an ArithmeticException
            //抛出异常后的代码不会执行
            System.out.println("Result: " + result);
        } 
        //捕获try中代码抛出的异常，参数是想要捕获的异常类型
        //从小到大捕获
        catch (ArithmeticException e) {
            System.out.println("Error: Division by zero is not allowed.");
        }
        //catch块可以有多个，捕获不同类型的异常
        catch (Exception e) {
            System.out.println("An unexpected error occurred: " + e.getMessage());
        }
        // finally块中的代码无论是否发生异常都会执行
        finally {
            System.out.println("This block is always executed.");
        }

        //throws关键字用于声明方法可能抛出的异常类型，调用该方法的代码必须处理这些异常
        try {
            LearnException obj = new LearnException();
            obj.test();
        } catch (Exception e) {
            System.out.println("Caught exception: " + e.getMessage());
        }

        //主动抛出异常
        try{
            throw new Exception("exception message.");
        }
        catch (Exception e) {
            throw new RuntimeException("This is a custom exception message.");
        }

        
    }

    public void test() throws Exception {
        throw new Exception("This is a test exception.");
    }
}

/*
输出：
Error: Division by zero is not allowed.
This block is always executed.
Caught exception: This is a test exception.
Exception in thread "main" java.lang.RuntimeException: This is a custom exception message.
        at Basics_of_java.chapter3.LearnException.main(LearnException.java:37)
*/
```

#### throws

用于方法声明处，表示该方法可能抛出的异常，将异常交给调用者处理。

```java
public static void test() throws Exception {
    throw new Exception("发生异常");
}
```

#### throw 和 throws 的区别

| 对比 | throw | throws |
|---|---|---|
| 使用位置 | 方法体内部 | 方法声明处 |
| 作用 | 主动抛出异常 | 声明可能抛出的异常 |
| 后面跟什么 | 异常对象 | 异常类型 |
| 数量 | 一次抛出一个对象 | 可以声明多个异常类型 |

#### 异常类型

| 类型 | 说明 | 是否必须处理或声明 |
|---|---|---|
| Checked Exception（检查异常） | 编译期间检查，如 IOException | 是 |
| RuntimeException（运行时异常） | 运行期间发生，如 ArithmeticException | 否 |

**注意：**
- 检查异常必须使用 try-catch 处理，或者使用 throws 声明。
- 运行时异常不需要强制处理或声明。
- throws 可以将异常继续向上层传递，由调用者处理。
